

# 基础电信企业网络与信息安全责任考核工作总体情况

**标准编号：** 工信部网安局〔2022〕

---

## 一、背景情况

### 考核工作的启动与实施

2012年，我部联合国资委印发《关于开展基础电信企业网络与信息安全责任考核有关工作的指导意见》，考核制度初步建立。

多年来，考核工作逐步推进，充分发挥"指挥棒"和"发令枪"作用，行业内监管工作有效配合、企业保障能力明显提升。

#### 考核工作发展历程

| 时间 | 重要事件 |
|------|----------|
| 2012年 | 联合发布《指导意见》 |
| 2013年 | 印发《考核办法》 |
| 2016年 | 正式启动省公司考核工作 |
| 2017年 | 增设1分属地化考核指标 |
| 2019年 | 专项考核专业公司检查全覆盖 |
| 2021年 | 正式启动专业公司考核工作；建立激励机制，增设1分加分项；加大警示力度，重点指标不设扣分上限 |
| 2022年 | 固化考核指标总体框架 |

### 1.考核办法制定目的和依据

**制定目的**

- 规范基础电信企业网络与信息安全责任考核工作

**编制依据**

- 《党委（党组）网络安全工作责任制实施办法》
- 《工业和信息化部 国务院国有资产监督管理委员会关于开展基础电信企业网络与信息安全责任考核有关工作的指导意见》

### 2.各主体考核工作定位与职责

| 主体 | 职责 |
|------|------|
| **部网安局** | 组织实施考核工作：开展宣贯培训、组织监督检查、核定评分结果、督促结果执行运用 |
| **通信管理局** | 负责辖区内省公司考核：制定属地化考核要点并实施、开展辖区内监督检查和评分工作 |
| **集团公司** | 负责所属省公司、专业公司考核：划定省公司与专业公司安全责任及考核界面、纳入绩效考核体系并严格执行、与干部综合考核评价挂钩 |
| **省公司、专业公司** | 责任落实：组织保障、制度建设、资金投入；责任分工：加强部门协同，明确责任分工，有效传导工作要求；内部监督：组织开展内部培训和检查 |

### 3.考核分值及组成

**扣分项**

- 占最终考核满分分值的6%
- 因未履行管理责任，发生重大网络和数据安全事件的情况，从严扣分
- 其余每项考核指标的扣减分值不超过满分分值的1%

**加分项**

- 对于主动承担管理和技术创新工作并有突出表现的予以加分
- 加分项分值不超过满分分值的2%（原占1%）
- 单项加分不超过满分分值的0.1%

**信息化支撑**

- 采取技术检测方式开展监督检查，减轻企业负担
- 部网安局组织建设考核系统，服务考核工作

---

### 4.考核要点制定原则

**聚焦范围**

- 贯彻中央领导同志重要指示批示精神和党中央、国务院重大决策部署
- 落实国家网络和数据安全法律法规体系
- 服务网络和数据安全重大工程、重要技术手段建设
- 支撑做好网络和数据安全重点监管工作、完成重要工作任务

**制定原则**

- 结果导向，避免设置过程性指标，提高可操作性
- 突出重点，严控考核指标数量，减轻企业负担
- 量化考核，科学、清晰设立考核指标，确保客观公正

### 5.考核要点组成

#### 省公司考核要点

| 指标类别 | 考核指标 |
|----------|----------|
| 一、重大网络和数据安全事件 | （一）重大网络和数据安全事件 |

| 三、重点监管工作 | （五）重要数据安全管理；（六）5G行业应用安全风险评估；（七）网络安全防护管理；（八）供应链风险防范；（九）特殊通信、通信管制等工作；（十）防范治理电信网络诈骗工作；（十一）电信业务实名制基础管理 |
| 四、属地化考核 | （十二）属地化考核 |
| 五、加分项 | （十三）创新试点工作 |

**属地化要点要求**

- 要点内容：对于已列入部统一考核的指标，原则上不纳入属地化考核
- 指标项目：扣分分值不超过满分分值的1%，指标不超过4项
- 印发及报备：每年3月底前印发并向部网安局报备

#### 专业公司考核要点

| 指标类别 | 考核指标 |
|----------|----------|
| 一、通用考核要求 | （一）重大网络和数据安全事件；（二）技术手段建设：资产安全管理平台、网络安全态势感知平台；（三）重点监管工作：重要数据安全管理、网络安全管理；（四）加分项 |
| 二、国际通信业务专业公司专项考核要求 | 防范治理电信网络诈骗 |
| 三、云（CDN）业务专业公司专项考核要求 | （一）互联网信息安全管理系统；（二）防范治理电信网络诈骗工作 |

| 六、卫星通信专业公司专项考核 | 特通工作保障 |

**专项考核要求**

- 扣分项：扣分值不超过满分分值的3%、指标不超过3项
- 加分项：加分项不超过6项
- 通用要求：考核指标合计不超过6项

### 6.监督检查工作指南

**监督检查工作指南**

- 部网安局依据年度考核要点明确监督检查事项、检查流程等内容，明确检查要求
- 各通信管理局可参照制定属地化指南

**统筹监督检查安排**

- 考核监督检查应与"双随机一公开"等行政执法检查事项统筹考虑，避免重复检查

**监督检查实施主体**

- 部网安局、各通信管理局、各集团公司组织开展，可委托专业技术机构开展考核检查
- 省公司、专项考核专业公司：由部网安局、各通信管理局、各集团公司组织检查
- 非专项考核专业公司：集团公司自行开展，次年2月底前将年度考核情况报部网安局

**中期检查**

| 项目 | 内容 |
|------|------|
| 检查时间 | 8月至10月 |
| 检查对象 | 省公司、专业公司 |
| 检查重点 | 考核工作推进与责任落实情况 |
| 结果运用 | 检查情况通报 |

**年度考核评分**

- 精简考核工作程序，"两上两下"工作机制优化为"初评、复核、通报"三个环节

| 环节 | 时间节点 | 工作内容 |
|------|----------|----------|
| 初评 | 12月底前 | 各管局、集团对省公司、专业公司进行初评打分，并报部网安局 |
| 复核 | 次年1月底之前 | 部网安局组织复核考核评分，对有争议的事项核实，确认评分结果 |
| 通报 | 次年2月底前 | 部网安局将考核评分结果报部同意后，书面通报各管局、集团 |

---

### 7.考核结果运用

**集团公司**

- 划清责任界面：划清相关部门责任界面，严格执行考核评分结果
- 纳入考核内容：评分结果作为对领导班子和有关领导干部综合考核评价的重要内容

**部网安局**

- 激励措施：连续三年考核靠前的省公司、专业公司，视情给予通报表扬、免于中期检查等激励措施
- 执行结果上报：每年3月底前上报上一年评分结果执行和运用情况

## 四、第四章 其他——考核工作纪律与回避原则

### 原则一：严守工作纪律

电信主管部门、各集团公司、接受委托的专业技术机构的工作人员在考核检查工作中，应严守工作纪律，严格执行考核要点及考核监督检查工作指南。

- 不得妨碍检查对象正常生产经营活动
- 不得收受检查对象给予的财务或者其他好处
- 对在履行职责中知悉的企业信息等，要严格保密，不得泄露、出售或者非法向他人提供

### 原则二：坚持回避原则

- 现场检查回避原则：检查主动回避一年内提供过与检查任务相关的安全服务的企业
- 例外事项：涉及国家秘密事项，须按政策授权由指定专业技术机构开展的考核检查任务除外

## 五、考核办法实施要求

各单位严格落实工作职责要求、规范操作流程，扎实开展考核管理工作，确保各环节工作有序开展。

1. **严格落实考核办法要求**
   - 各单位建立健全安全责任考核工作机制，固化有益工作做法，对流程机制相关调整情况，及时组织宣贯学习

2. **健全安全责任考核机制**
   - 严格落实考核办法要求

3. **强化重点工作落地成效**
   - 各单位准确把握关键节点，做好工作安排，注重结果导向，提升考核工作效率，推进重点任务快速落地

## 2022年考核要点总体情况

### 一、2022年考核要点编制思路

3月21日，以厅文形式正式印发考核要点，包含省公司、专业公司考核要点。

1. **坚持结果导向**
   - 避免设置过程性指标，提高可操作性，切实推动企业网络和数据安全责任落实

2. **坚持突出重点**
   - 凝练聚焦，严控考核指标数量，技术手段建设、重点监管工作设置的考核指标合计不超过10项，加分项不超过6项，引导企业突出重点

3. **坚持量化考核**
   - 科学、清晰设立考核指标，细化完善考核要求，明确具体评分标准，确保客观公正

### 二、2022年考核要点分值情况

2022年考核要点由扣分项和加分项组成。扣分总分值为6分（按600分计），采用扣分形式，直至扣完为止。加分总分值不超过2分（按200分计），在集团公司对各省公司绩效考核体系中最高可加2分。

| 分值类型 | 分值 |
|----------|------|
| 扣分总分值 | 6分（按600分计） |
| 加分总分值 | 不超过2分（按200分计） |
| 单项分值 | 0.01分-0.03分、0.05分、0.1分 |

### 五、加分项考核要点

企业围绕部网络和数据安全重点工作，主动承担管理和技术创新试点工作并有突出表现的予以加分，根据工作表现和贡献情况，分别加5分、10分。

| 序号 | 加分领域 | 具体内容 |
|------|----------|----------|
| 1 | 网络安全 | 参与部组织的网络安全演练；网络攻击IP准确溯源与对接；入驻国家网络安全产业园区；入选部网络安全试点示范工作 |
| 2 | 数据安全和5G | 虚拟货币网络挖矿监测处置；深度合成检测处置；数据安全风险监测和处置（扩展风险监测类型）；信安系统升级改造；"绽放杯"5G应用安全专题赛；5G应用安全创新示范中心；《5G安全指南》实施成效评价 |

## 2022年监督检查工作指南总体情况

### 一、编制情况

**编制目的**

- 提供2022年安全考核落地支撑：按照《基础电信企业网络与信息安全责任考核办法》要求、2022年省公司和专业公司考核要点与评分标准，组织做好2022年基础电信企业网络与信息安全责任考核工作落地实施

**指南组成**

- 三份检查工作指南分册：公开部分分册、供应链部分分册、重要通信部分分册

### 二、重点内容

**检查事项**

- 包括指标事项、检查流程、违规场景、取证内容

**检查方法**

- 包括使用的方式方法、技术手段等

**场景化明确检查工作要求**

- 检查方法：人员访谈、材料查阅；实地技术核验；网络联通测试；系统指令下发；核查企业上报材料
- 违规场景：企业易遗漏的工作事项；企业工作落实程度不足情况；企业未把握关键时间节点情况；工作落实佐证缺失情况

### 三、应用场景

**监督检查、考核评分**

- 各管局、集团应按照《监督检查工作指南》组织开展考核监督检查和评分工作，严格遵循检查流程、对标违规场景逐一核实，针对问题情况留存取证材料

**企业对标自查**

- 各省公司、专业公司要按照《监督检查工作指南》从严落实考核要求，规避违规情况的发生，定期组织内部开展自查和问题整改工作

## 关键条款

- **第三条：** 考核分值由扣分项和加分项组成，扣分项占最终考核满分分值的6%，加分项分值不超过满分分值的2%
- **第五条：** 考核要点聚焦贯彻中央决策部署、落实法律法规、服务重大工程、支撑重点监管工作
- **第八条：** 连续三年考核靠前的省公司、专业公司，视情给予通报表扬、免于中期检查等激励措施
- **第十条：** 监督检查应与"双随机一公开"等行政执法检查事项统筹考虑，避免重复检查
- **第十一条：** 严守工作纪律，不得妨碍检查对象正常生产经营活动，不得收受检查对象给予的财务或者其他好处
- **第十二条：** 现场检查应回避一年内提供过与检查任务相关的安全服务的企业
