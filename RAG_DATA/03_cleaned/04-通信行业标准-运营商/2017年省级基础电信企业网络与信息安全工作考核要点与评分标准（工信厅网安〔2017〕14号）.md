

# 2017年省级基础电信企业网络与信息安全工作考核要点与评分标准

**标准编号：** 工信厅网安〔2017〕14号

## 说明

1、考核总分值为600分，信息安全管理、网络安全管理 和重要通信管理三部分均采用扣分形式，直至5分扣完为止。

2、部分单项评分计算方法另行通知。

3、省级铁通公司网络与信息安全工作情况纳入省级移动公司统一考核。

## 关键条款

- **第一条（考核总分）：** 考核总分值为600分，信息安全管理、网络安全管理和重要通信管理三部分均采用扣分形式，直至5分扣完为止。

- **第二条（属地化监管）：** 各通信管理局根据属地化工作实际，可将信息安全机构运行情况、网络与信息安全专职人员教育培训情况、通讯信息诈骗与"扫黄打非"等专项工作纳入考核，2017年3月31日前向部网络安全管理局报备。

- **第三条（信息安全专职人员）：** 发现一名专职信息安全人员不掌握信息安全相关法规和制度要求，未具备必要的信息安全管理技能的，扣2分。

- **第四条（IDC/ISP系统功能）：** 在2017年3月至12月期间，每次发现一项不达标的系统功能，扣2分。

- **第五条（IDC/ISP系统可靠性）：** 每发现一次企业系统可靠性不合格，扣5分。

- **第六条（基础数据）：** 每发现一条不合格数据，扣2分；企业未按要求对异常数据进行更新上报的，发现一次扣5分。

- **第七条（系统使用及安全）：** 企业未按要求制定完善的系统使用及运行维护管理实施细则的，扣5分；未配备与业务规模相匹配的专职系统使用人员（至少两名）的，扣5分。

- **第八条（通讯信息诈骗工作机制）：** 未按要求成立省公司防范打击通讯信息诈骗工作领导小组及办公室，扣5分。

- **第九条（举报通报）：** 发现1起重点电信业务违规问题扣2分，发现2起及以上扣5分。

- **第十条（实名率）：** 全部电话用户实名率与目标要求每差0.1个百分点，扣10分。

- **第十一条（新入网实名）：** 实体渠道每发现一起违规办理电话用户入网手续的，扣5分。

- **第十二条（行业卡实名）：** 电信企业未按要求对行业卡进行实名登记，每发现一张扣5分。

- **第十三条（网络安全事件）：** 导致发生特别重大用户个人信息泄露事件的，发生一次扣100分。

- **第十四条（特殊通信）：** 发生一次违规接入特殊通信系统的，扣除50分；发生泄密事件的，每发现一次扣除50分。
