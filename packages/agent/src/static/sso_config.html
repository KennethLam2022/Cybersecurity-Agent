SSO / 企业身份集成

配置 LDAP/AD 绑定登录或 OIDC 授权码登录；首次登录按企业策略自动开通或进入管理员审批。

用途与边界
SSO 与本地密码账号并存，管理员可启用任意组合。LDAP 服务账号与 OIDC Client Secret 只以加密形式存储，前台接口仅返回启用中的登录入口，不暴露密钥。新建账号沿用现有工作区、角色与 Agent 隔离边界。
