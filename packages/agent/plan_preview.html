📥 数据迁移方案 migration

一次性的迁移逻辑：应用启动时检测 prompt_test_items 是否为空，若为空则将 prompt_test_suite.json 中的 31 条导入数据库。
def migrate_suite_to_db(db: DatabaseManager):
"""将 JSON 中的 31 条测试题迁移到数据库"""
count = db.query("SELECT COUNT(*) FROM prompt_test_items WHERE set_id='builtin'")
if count > 0:
return # 已迁移，跳过

suite = json.loads(Path("agent_data/prompt_test_suite.json").read_text())
for i, case in enumerate(suite["test_cases"]):
db.execute("""
INSERT INTO prompt_test_items
(set_id, seq, query, category, difficulty, expected, is_active)
VALUES ('builtin', ?, ?, ?, ?, ?, 1)
""", (i+1, case["query"], case["category"], case.get("difficulty","medium"),
json.dumps(case.get("expected",{}), ensure_ascii=False)))
db.commit()
✅ 迁移完成后：
  • 旧 Tab 的 load_suite() 改为从 DB 读 → 和后端代码统一
  • 新 Tab 直接读 prompt_test_items WHERE set_id='builtin' → 31 条
  • AI 生成的测试题写入 set_id='ai_时间戳' → 两套不冲突
  • JSON 文件保留不动（作为备份），但不再作为运行时数据源
