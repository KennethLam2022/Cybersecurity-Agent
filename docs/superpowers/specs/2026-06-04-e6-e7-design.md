## E6 退化预警

### 触发逻辑（双重检测）

**① 目标阈值兜底**
单次评测任一指标低于目标值，立即告警：

| 指标 | 目标阈值 |
|:-----|:---------|
| Context Precision | < 0.80 |
| Context Recall | < 0.70 |
| Faithfulness | < 0.85 |
| Relevancy | < 0.80 |
| Hallucination（越低越好）| > 0.10（反向告警）|

**② 趋势预警**
历史评测记录 ≥ 2 次时，同一指标连续 N 次（默认 N=2，可配置）持续下降则告警。

### 展示位置

**概览看板顶部横幅**，格式：
```
⚠️ 退化警告：Context Recall 连续2次下降（0.85 → 0.78 → 0.71）
```

有退化时显示红色横幅（`var(--r)`），点击可查看详情。趋势恢复正常后自动消失（连续2次持平或回升）。

### 前端实现

在 `loadDash()` 成功后（概览看板 Tab 被激活时），读取 `versions` 数组，执行退化检测逻辑，结果存入全局状态 `window._degradationAlerts = []`，模板底部横幅根据此状态显示/隐藏。

## E7 趋势图

### 图表规格

**类型**：ECharts 折线图（line）
**位置**：概览看板 Tab 底部（现有内容之后）

### 数据

- X 轴：评测时间（取 `timestamp`，显示 MM-DD HH:mm）
- Y 轴：指标分数（0 ~ 1）
- 5 条线：CP / CR / FT / RL / HC（对应 context_precision / context_recall / faithfulness / relevancy / hallucination）

### 交互

- legend 可点击切换显示/隐藏单条线
- tooltip 显示所有指标的具体值
- 数据点 hover 高亮

### 配色

| 指标 | 颜色 |
|:-----|:-----|
| CP（Context Precision）| `#0071e3`（蓝）|
| CR（Context Recall）| `#34c759`（绿）|
| FT（Faithfulness）| `#af52de`（紫）|
| RL（Relevancy）| `#ff9500`（橙）|
| HC（Hallucination）| `#ff3b30`（红，越低越好）|
