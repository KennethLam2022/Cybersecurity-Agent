## 详细记录

### 1. 配置生效链路流程图（admin_model_preview.html）

- **发现问题**：Flex + wrap 布局下，⑦⑧ 卡片被挤到第二行且描述文字被截断
- **修改过程**：
  - flex wrap → CSS Grid → 最终 `grid-template-columns: repeat(4, 1fr)`
  - 移除 `min-height`，改用 `align-items: stretch` 自适应
  - 卡内边距 `padding: 28px 16px 20px`，gap 16px
- **验证**：Chrome F12 逐轮确认显示完整

### 2. API Key 加密初始化顺序 Bug

- **根因**：`main.py` 第21行 `from agent import CyberAgent` 在加密初始化（第30-58行）之前执行，导致 `memory.py` 在 `_load_encryption_key()` 时读不到环境变量，解密失败 → Key 为空 → OpenRouter 401
- **修复**：加密初始化代码移至 `import` 之前，先设置 `os.environ["LLM_KEY_ENCRYPTION_KEY"]` 再导入 agent
- **验证**：重启后 OpenRouter 返回 200，scoring 日志 `source=scoring_card`

### 3. Embedding 维度不匹配 (512→1024)

- **发现**：向量库为 512 维（quentinz/bge-small-zh-v1.5），硅基 `BAAI/bge-large-zh-v1.5` 为 1024 维 → Chroma 报错
- **决策**：还原为生产环境 `OllamaEmbeddings + quentinz/bge-small-zh-v1.5`，避免重建向量库

### 4. 启动时读取新版 chat 卡片配置

- **根因**：`_init_on_startup()` 只读旧版 `llm_config.json` 的 `current` 字段，不读新版 SQLite `llm_configs` 表中的 `chat` 卡片
- **修复**：优先读取 `chat` 卡片，无卡片时回退到旧配置
- **验证**：重启后日志显示 `已加载 LLM 配置 (chat卡片): 阿里云百炼 / qwen3.5-flash`

### 5. 前台LLM配置同步后台 + 后台变更通知前台（热更新不重启）

- **前台保存** → `agent.llm` 热更新 + 同步写入后台 `chat` 卡片 + SSE 通知 admin 看板
- **后台保存** → `agent.llm` 热更新 + 前台轮询检测 `/api/llm/config/current` → 弹窗通知
- **Key 防丢失**：`_save_llm_config_card` 在 Key 为空时自动从 `llm_provider_keys` 表补回
- **前台误通知修复**：用户自己保存后更新 `_lastConfigProvider` 缓存，避免轮询误弹

### 6. 文档入库页面（data_preview.html）去 Mock 化

- **之前**：100% Mock 数据，没有真实 API 调用
- **后端实现**：
  - `POST /api/documents/scan` - 上传文件 + MD5 校验 + 重名检测
  - `POST /api/documents/start-processing` - 解析 → LLM 清洗 → 保存 MD → 重建向量库
  - `GET /api/documents/status/{task_id}` - 轮询进度（解析/清洗/重建各阶段）
- **前端实现**：拖入/选择文件 → 真实扫描 → 冲突处理 → 批量处理 → 进度条

### 8. 增量索引 pipeline（incremental_index.py）

**背景**：之前每次上传文档后，后台 `_rebuild_vectors()` 全量跑 build_parent_index + rebuild_faiss + rebuild_chroma 三个脚本，随着文档增多耗时越来越长。

**新建文件**：`packages/preprocessor/src/incremental_index.py`

**增量策略**：

| 索引 | 方式 | 说明 |
|:----|:-----|:------|
| 父文档索引 | `_update_parent_index()` | 加载 `parent_texts.json`，按 `parent_id` 去重，追加新节 |
| FAISS | `_add_to_faiss()` | 加载现有 `index.faiss`，按 `chunk_id` 去重后追加，临时目录绕开中文路径 |
| Chroma | `_add_to_chroma()` | 获取现有 collection，去重后追加 documents |
| BM25 | 自动重建 | 启动时从 `parent_texts.json` 自动重编，无需手动 |

**删除文件**：`packages/agent/src/add_doc_to_index.py`（被 incremental_index.py 替代）

**删除旧函数**：`main.py` 中的 `_rebuild_vectors()`（全量）→ `_incremental_index()`（增量）

**修复的 bug**：
- `_process_single_file()` 中 `OdlParser(str(path))` 旧 API 调用错误 → 改为 `OdlParser().parse(str(path))`
- `_process_single_file()` 中 `cleaner.clean_chunks()` 方法不存在 → 改为 `cleaner.clean_document()`

### 10. OCR 方案测试（DeepSeek-OCR → 回退 RapidOCR）
