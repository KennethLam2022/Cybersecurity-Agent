## 详细改动记录

### 1. 评测管线修复

**根因**：Python `str.format()` 中未转义的 `{}` 导致 KeyError。5 个评分 prompt（`_eval_generation.py` 3 个 + `_eval_context.py` 2 个）中的 JSON 示例 `{"score": ...}` 被 `format()` 误解析为占位符。

**修复**：
- 所有 prompt 中 JSON 示例的 `{` → `{{`，保留 `{query}` `{context}` `{answer}` 占位符不变
- 统一 `_llm_judge()` 助手函数：`temperature=0.01` + `_extract_json()` + 统一异常处理
- 加 `_clean_answer()`：评分前移除 `【思考过程】` 和 `[来源N: ...]` 元数据

**涉及文件**：`_eval_generation.py`, `_eval_context.py`, `main.py`

### 2. 去除"运营商"特指

**改动**：8 个文件中所有涉及"移动运营商""运营商"的关键词清理
- `agent.py`：System Prompt、招呼回复共 10 处
- `main.py`：评测 LLM prompt、Word 导出 footer、测试题生成 prompt 共 6 处
- `eval_e2e.py` / `eval_30_v3.py` / `prompt_test_manager.py`：测试题表述
