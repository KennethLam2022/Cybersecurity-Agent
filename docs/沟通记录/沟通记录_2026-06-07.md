## 详细记录

### Bug 1：单题跑分后图表不显示

**根因**：API `/api/prompt/test/latest` 返回 `{results: [{...report}]}`，但前端直接读取 `report.xxx` 而不是 `results[0].xxx`，导致 `dimension_scores` 为 undefined，图表不渲染。

**修复**：
- `loadLatestPromptResult()` 改为 `results[0]` 读取
- 移除 `loadLatestPromptResult()` 中对弹性面板的 `style.display='none'` 强制隐藏
- `switchPromptView()` 增加清除 inline 样式逻辑
- 页面初始加载改为预取数据但不渲染图表，等切到 Prompt tab 再渲染

### Bug 2：单题跑分结果刷新后丢失

**根因**：`run_single` 后端不写库，`get_latest_full_result()` 查 `prompt_test_results` 表无数据。

**修复**：`routes_api.py` 中 `/api/prompt/test/run-single/{item_id}` 在跑完后写入 `prompt_test_results` 表（之前只有 run-all 才写）。

### Bug 3：弹性测试图表读取不到数据

**根因**：`renderElasticCharts(d)` 直接读 `d.consistency_details`，但 DB 存的数据在 `d.dimension_scores` 下。

**修复**：先查 `d.dimension_scores.consistency_details`，没有才 fallback。
