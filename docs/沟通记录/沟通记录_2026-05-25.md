### 两个失分点根因分析（2026-05-25 晚间排查）

#### YD11（3/15）：「YD/T 2692-2014找不到」

**根因：chunk_size=300 太细 + top_k=10 不足**

| 维度 | 数据 |
|:-----|:-----|
| 文档总字符 | 9,089 |
| Section 4（安全防护要求，含4.1~4.5） | 约5,000+ 字符，含30+子节 |
| chunk_size=300 切片 | Section 4 → ~16个chunk；Section 1-3 → ~10个chunk |
| top_k=10 | 只有10个chunk能进LLM上下文 |

**实际召回结果**（从 eval JSON 核实）：
- Top-10 中来自 YD/T 2692-2014 的 chunk **只有4个**，且全部来自**前言、范围、规范性引用文件**
- Section 4（4.1.2 技术要求、4.2.2 技术要求等技术要点）的chunk**一个都没进来**
- 剩余6个位置被 YDT 2694/2695/2696/2697 的"规范性引用文件"占用

**机制解释**：问题含"技术要求"关键词，"前言"和"范围"节因含"安全防护要求"等泛关键词得分更高；Section 4 的具体技术要求内容虽然相关，但被切成很多小chunk，每个小chunk的语义密度不够，排到了11+位被截断。

**修复方案**：
- ✅ 方案A（推荐）：chunk_size=300 → **500**，减少碎片化；top_k=10 → **20**，扩大召回池
- ⚠️ 方案B：仅增大 top_k，不改 chunk_size（召回更多小chunk但质量不稳定）
- ⚠️ 方案C：仅改 chunk_size，不改 top_k（chunk 更完整但池子不变，仍有漏召回风险）

#### DJ13（5/15）：「等保四级与三级区别不会对比」

**根因：Prompt 缺乏「对比推理」引导**

问题"等保四级与等保三级的主要区别体现在哪些安全要求上？"要求Agent做两步推理：
1. 同时检索等保三级和等保四级的要求
2. 对比分析差异

当前 Agent 的行为模式是**直接回答型**——从检索到的文档中找直接匹配q的答案。对于"区别/差异"类问题，没有显式引导去做对比推理。

**修复方案**：
- 在 System Prompt 的「回答原则」中增加第8条：**"当用户问'区别''差异''对比'时，必须分别检索两个对象的要求后做对比分析"**
- 另加一条 One-shot 示例展示对比回答格式

**注意**：这个问题不是知识库缺失——知识库中有等保三级和等保四级的内容。问题是Agent没想到/不会同时查两边的信息再做推理。
