### [Hotfix] llm_provider.py 日志文案误导

- **发现问题**：日志 `SiliconFlow 调用失败（熔断或重试耗尽）: 401 Unauthorized for url: openrouter.ai`
- **根因**：内部方法名 `_try_siliconflow`、`_siliconflow_with_retry` 及所有日志文案写死 "SiliconFlow"，但实际用 `self.base_url` 动态请求
- **修改范围**：`llm_provider.py`
  - `_try_siliconflow()` → `_try_provider()`
  - `_siliconflow_with_retry()` → `_provider_with_retry()`
  - `chat()` 阶段1注释 `SiliconFlow` → `主 LLM 调用`
  - `chat_stream()` 阶段1注释 `SiliconFlow 流式` → `主 LLM 流式调用`
  - 所有 `logger.warning` 文案去掉 `SiliconFlow`，改为 `LLM`
