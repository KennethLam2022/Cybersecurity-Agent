📐 对话界面布局，你倾向哪种？

核心交互就是提问→回答，布局决定了使用体验

A

全屏对话

类似 ChatGPT/DeepSeek 的经典布局：顶部 Header，中间对话流，底部输入框。简洁专注，用户上手零学习成本

┌─────────────────────────────┐
│ 网络安全管理Agent ⚙️设置 │
├─────────────────────────────┤
│ │
│ 用户：5G核心网等保三级要求？ │
│ ┌─────────────────────┐ │
│ │ Agent 回复... │ │
│ └─────────────────────┘ │
│ │
│ ─────────────────────── │
│ [ 输入问题... ] [发送] │
└─────────────────────────────┘
B

对话 + 侧边栏

经典对话 + 左侧历史会话列表/知识库导航。适合需要管理多个话题、查阅不同知识领域的场景

┌──────────┬──────────────────┐
│ 历史会话 │ 网络安全管理Agent │
│──────────│ │
│ 📄 等保 │ 用户：5G核心网？ │
│ 📄 CII │ Agent 回复... │
│ 📄 数据 │ │
│ 📄 APP │ [输入...] [发送] │
│──────────│ │
│ + 新对话 │ │
└──────────┴──────────────────┘
C

对话 + 知识库面板

右侧额外展示"引用来源"面板。当 Agent 引用标准条款时，右侧同步展示原文出处。适合需要溯源验证的场景
