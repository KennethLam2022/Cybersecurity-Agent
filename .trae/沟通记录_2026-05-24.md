### ChromaDB #7090 Compaction Bug

- **现象**：写入成功（7316 chunks，exit 0），重读报 `InternalError: Error loading hnsw index`
- **根因**：Rust HNSW compactor 写 pickle 时 float/int 序列化不匹配
- **workaround**：`hnsw:sync_threshold=100000`（大于总嵌入数），compactor 永不运行
- **验证结果**：写入 7316 ✓ → 重开 client ✓ → 查询 ✓

### 下午-晚上：Prompt 设计 + 50题评估

#### Prompt 迭代（基于知识库 Prompt Engineering 原则）

| 版本 | 架构 | 问题 | 修复 |
|------|------|------|------|
| v0（原始） | 3行通用原则 | 无角色定位、无约束、无示例 | → 重写 |
| v1 | 42行三层架构：角色+约束+Context+CoT+One-shot | 模型输出思考过程表，不是回答 | 去掉User Prompt中"先分析"指令，删除One-shot中【思考过程】 |
| v2（当前） | 结构：核心结论→详细分析→操作提醒 | 来源标注只有[来源3]无文档名 | → `[来源N: 文档名称 / 章节]` |
| v3 | 引用格式加强制约束 | 引用章节信息不够明确 | → 说明放在输出格式规范最前面 |

**当前 System Prompt 核心要素**：
- 角色定位：运营商网络安全管理专家
- 5个能力领域 + 明确不做范围
- 5条回答原则（严格基于文档、区分红线/优化、直白接地气、整改方案、操作提醒）
- 输出格式规范含来源标注格式 `[来源N: 文档名 / 章节]`
- 关键规则：只输出最终答案，不展示思考过程
- One-shot 示例：等保三级访问控制
